Graph content

What the CTI graph shows

Scenario

The graphs describe the spread of GoTrim, a distributed botnet, and its behaviour in the network.

Node information

Each node can show an ID, a node type, a connection count labeled as size, and a TLP access level.

Edge information

Edges represent relations between nodes and include a relation type plus a numerical confidence level.

Visual versions

During the study, the graph you see can appear in three different forms. The same information is always present — only the way it is shown changes.

No encoding

No visual encoding — all information is shown as text only, with no shape, colour, or size adaptations.

Partial encoding

Partial visual encoding — only one of the visual adaptations explained later is applied; the rest stays as text.

Full encoding

All visual encoding — every adaptation explained later is applied across the graph at the same time.

Graph content

Node variables

Each node represents a network item in the threat intelligence graph. These are the variables you will see on nodes.

Node type

The type of observed network item. Three values:

  • Cyber Observable — Raw data or events (IPs, domains, file hashes, registry keys, HTTP requests). Building blocks for spotting suspicious or malicious activity.
  • Attack Pattern — Common attacker methods or techniques (phishing, SQL injection, privilege escalation). Helps recognize how attacks are carried out.
  • Malware — Software designed to harm systems (viruses, worms, ransomware, trojans). CTI covers families, behaviours, and related indicators.

Node TLP level

Traffic Light Protocol — who may access or share the information:

  • Clear — May be shared publicly. No distribution restrictions.
  • Green — Share within the community and with partner organisations, not publicly.
  • Amber — Limited sharing within the organisation or community; need-to-know for cybersecurity purposes.
  • Red — Restricted to specific individuals only. Highly sensitive.

Node size

The total number of internet connections to that network item.

Scored 1–10 — higher values mean more connections.

Graph content

Edge variables

Edges connect two nodes and describe how they relate. These are the variables you will see on edges.

Edge confidence

How confident we are that two items are actually related — essentially, how strong the link is believed to be.

Scored 1–10 — higher values mean stronger confidence in the relationship.

Relationship type

What kind of link exists between two nodes. Four values:

Uses — Links an Attack Pattern or Threat Actor to a tool, malware, or technique it employs.
Based_on — One item is derived from or influenced by another (e.g. an Indicator based on an Observable such as an IP).
Indicates — Links an Indicator to the threat it suggests (e.g. a domain indicating malware activity).
Mitigates — Links a Course of Action to what it helps defend against (e.g. a firewall rule mitigating port scanning).

Encoding guide

Node encodings (only when this visual adaptation is active — the graph should look different from before, and the encoded information is shown only through its visual form, not as text)

Node type → shape

Attack Pattern = square
Cyber Observable = circle
Malware = triangle

TLP level → color

TLP Clear = white
TLP Green = green
TLP Amber = orange
TLP Red = red

Connection count → node size

1–3 = small
4–6 = medium
7–10 = large

Encoding guide

Edge encodings (only when this visual adaptation is active — the graph should look different from before, and the encoded information is shown only through its visual form, not as text)

Confidence level → line thickness

1–3 = low confidence
4–6 = medium confidence
7–10 = high confidence

Edge type stays as text

  • Uses
  • Mitigates
  • Based_On
  • Indicates

These labels remain written on the edge even when other properties are visually adapted.
