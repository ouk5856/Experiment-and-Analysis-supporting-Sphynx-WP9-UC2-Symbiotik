WP9 Use Case 2 Evaluation

CTI Graph Adaptation Study

Experiment design, protocol changes, and analysis results — does visual adaptation help people read Cyber Threat Intelligence (CTI) graphs, and do image features track that help?

N = 13 624 trials 48 stimuli

Idea

What we set out to do

01

Paradigm

Graph question-answering task analogous to deliverable D2.2, using Sphynx CTI / GoTrimm material, redesigned for inter-subject correlation (ISC) analysis.

02

Focus

Primary contrast: adaptation (non / semi / full). Graph size and question level are secondary context.

03

Questions

Does adaptation ease the task? Do sensors show shared dynamics? Can image features act as proxies for human data?

ISC constraint: fixed identical timing across participants (no self-pacing) — required so shared stimulus-locked dynamics can be compared (Nastase et al., 2019).

Design

What changed from the partner material

Why redesign

  • • Low-res / inconsistent screenshots
  • • Incomplete or incorrect adaptations
  • • Unrealistic Security Operations Centre (SOC) samples
  • • Original features not usable on those images

Final protocol

  • • Graphs rebuilt; 6 & 12 nodes kept
  • • Node types 5 → 3; Traffic Light Protocol (TLP) as colour
  • • Graph viewing 18 s
  • • Fixed breaks between trials; long break after ~20 minutes

Non-adapted

Text only — no visual encoding

Semi-adapted

One encoding applied

Fully adapted

All encodings applied

Adaptation encodings

Analysis

Four-step analysis flow

1 · Behaviour

Response time (RT) & accuracy across adaptation (linear mixed model / MixedLM; clustered logit).

2 · ISC

Electroencephalography (EEG), eye-tracking, photoplethysmography (PPG), electrodermal activity (EDA).

3 · Image features

Digital ink, utility, synthetic saliency (SUM, ViSalFormer), synthetic scanpath (CLIPGaze).

4 · Proxy check

Do image features track human RT / accuracy / ISC patterns?

Data collected: behaviour · eye-tracking (GazePoint) · EEG · PPG · EDA. Same adaptation conditions throughout.

Results · Image features vs humans

Most features miss adaptation — and none proxy humans

Adaptation focus: except digital ink (non vs full, FDR ≈ .031), image features do not significantly distinguish the main adaptation conditions after FDR. Utility / SUM / CLIPGaze may split by graph size or question — not by adaptation. ViSalFormer has no FDR-significant condition splits.

Verdict

Three bullets to remember

1

Humans: adaptation helps

Significant faster RT and higher accuracy for semi/full vs non (MixedLM / clustered logit). Same direction as D2.2 when adaptation matches the question.

2

Sensors: harder → more shared ISC

Non-adapted yields significantly higher GFP, gaze Y, and EDA ISC than full adaptation — more shared processing when encoding help is absent.

3

Image features: not a stand-in for humans

Aside from digital ink, they mostly do not separate adaptation conditions — and they are not significant proxies for the human RT/accuracy benefit under paired FDR tests.
