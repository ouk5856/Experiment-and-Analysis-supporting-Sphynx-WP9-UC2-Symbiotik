POST_ANALYSIS — IMAGE FEATURES vs HUMAN DATA (Sphynx-13)
N participants = 13, N stimuli = 48. Spearman. FDR-BH within each outcome.

WHY THIS SCRIPT EXISTS
Behaviour already showed that full adaptation helps (faster, more accurate).
Script 03 only showed that some image statistics differ by condition label.
That can be true even if the feature has nothing to do with human load.
Here: do feature values (and non−full deltas) track RT / accuracy / ET / ISC?

Three questions:
  1. Stimulus-level: on images with feature X, are people slower / less accurate?
  2. Residual: after removing adaptation + nodes + question, does X still track RT?
     If no, X is mostly restating the design. If yes, X captures extra image difficulty.
  3. Paired benefit: for the same question, does a bigger feature change (non vs full)
     go with a bigger RT/accuracy benefit?

Stimuli joined: 48  |  median RT 8.48s  |  mean accuracy 0.763

HOW TO READ THIS
A useful adaptation-engine feature should (a) survive FDR in the paired test or
the residual test, not only the raw stimulus correlation, and (b) move in the
same direction as the human benefit (more marks / flatter saliency → faster RT).
CLIPGaze vs human ET tests whether predicted scanpaths resemble real looking.
